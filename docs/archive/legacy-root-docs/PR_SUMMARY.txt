COMMIT MESSAGE

feat(gui): integrate real LLM responses via Ollama neural-chat

Integrate Ollama neural-chat model with Ghostlink GUI to provide real LLM 
responses instead of mock echo responses. Implements a proxy server that routes
chat requests to Ollama's /api/generate endpoint.

Breaking Changes: None
Risk Level: Low
Rollback: git revert <commit-hash>

================================================================================
HOW TO USE
================================================================================

Preflight Check:
  python3 scripts/launch_studio.py --check

Full Launch:
  python3 scripts/launch_studio.py

Or with bash (Windows/macOS/Linux):
  bash scripts/launch_studio.sh --check
  bash scripts/launch_studio.sh

Requirements:
  - Ollama installed (https://ollama.com)
  - Python 3.9+
  - ~500MB disk for neural-chat model
