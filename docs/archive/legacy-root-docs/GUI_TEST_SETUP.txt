# Ghostlink GUI Test Suite with Real LLM

## Summary

Fixed the `quickstart.sh` requirements.txt issue and created a comprehensive GUI testing setup that uses **Ollama with tinyllama** (a real, lightweight LLM) instead of mock responses.

## What Was Fixed

### Problem 1: Missing requirements.txt
- The `quickstart.sh` script is Rust/Cargo-based
- The GUI is Python but had no `requirements.txt`
- **Solution**: Created `requirements.txt` with GUI dependencies

### Problem 2: Mock Responses in Chat
- GUI had no real backend to connect to
- All responses were placeholders
- **Solution**: Created a minimal backend server that proxies to Ollama with real LLM responses

## Files Created

### 1. requirements.txt
Python dependencies for the GUI and backend:
```
requests==2.31.0
huggingface-hub==0.21.4
```

### 2. scripts/backend_test_server.py
Minimal HTTP backend that:
- Implements the Ghostlink API (`/health`, `/api/models`, `/api/inference/chat`, etc.)
- Proxies chat requests to Ollama for real LLM responses
- Provides mock metrics, sessions, and worker endpoints
- Runs on `http://127.0.0.1:8003`

### 3. scripts/test_gui_functions.py
Automated test suite (15 tests) that verifies:
- Backend health and connectivity
- Real Ollama models loaded (no mock data)
- Chat endpoint returns actual LLM responses
- All endpoints (metrics, sessions, workers, security)
- Concurrent request handling
- No mock/placeholder keywords in responses

### 4. scripts/test_gui_with_ollama.sh
Test orchestration script that:
- Checks Ollama is running and tinyllama is available
- Installs Python dependencies
- Starts backend test server
- Runs the full test suite
- Provides helpful error messages

### 5. docker-compose.gui-test.yml
Single-command Docker setup with:
- Ollama service (auto-pulls tinyllama)
- Backend test server
- Proper networking and health checks

### 6. Dockerfile.gui-test
Container image for the backend test server

### 7. TESTING_GUI.py
Setup and troubleshooting guide (this file when run shows all instructions)

## Quick Start

### Option 1: Local Setup

```bash
# Step 1: Install Ollama
curl https://ollama.com/install.sh | sh

# Step 2: Start Ollama with tinyllama
ollama run tinyllama

# Step 3: In another terminal, install dependencies
python3 -m pip install -r requirements.txt

# Step 4: Run the test suite
bash scripts/test_gui_with_ollama.sh

# Step 5 (optional): Start the GUI
python3 ghostlink_gui.py
```

### Option 2: Docker Setup

```bash
# One command to start both Ollama and backend
docker-compose -f docker-compose.gui-test.yml up

# In another terminal, run tests
bash scripts/test_gui_with_ollama.sh
```

## Troubleshooting

### "Ollama not running on localhost:11434"
```bash
# Install Ollama
curl https://ollama.com/install.sh | sh

# Start Ollama with tinyllama
ollama run tinyllama
```

### "Backend did not start"
```bash
# Check backend logs
cat /tmp/ghostlink_backend.log

# Verify port 8003 is free
lsof -i :8003
```

### "tinyllama model not found"
```bash
# Pull the model (~405MB, takes a few minutes)
ollama pull tinyllama
```

### "GUI shows Backend offline"
```bash
# Start backend manually
python3 scripts/backend_test_server.py

# In another terminal, test health
curl http://127.0.0.1:8003/health
```

### "Requirements install failed"
```bash
# Upgrade pip first
python3 -m pip install --upgrade pip

# Then install requirements
python3 -m pip install -r requirements.txt
```
