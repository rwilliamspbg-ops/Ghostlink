# GUI Real LLM Integration - Neural-Chat via Ollama

## Overview
This PR integrates Ollama's neural-chat model with the Ghostlink GUI to provide real LLM responses instead of mock echo responses. A new proxy server routes chat requests to Ollama's inference API, enabling full end-to-end AI chat functionality.

## Problem Statement
Previously, the GUI chat tab returned mock/echo responses instead of real LLM inference. Users could not interact with an actual language model. This PR solves that by:
1. Creating a real LLM proxy that connects to Ollama
2. Routing all chat requests through the proxy to neural-chat model
3. Supporting configurable LLM parameters (temperature, system prompts, etc.)
4. Providing cross-platform launch experience with dependency validation

## Solution Architecture

```
GUI (Tkinter)
    ↓ HTTP (port 9999)
Real LLM Proxy (real_llm_proxy.py)
    ↓ HTTP (port 11434)
Ollama Server
    ↓ Inference
neural-chat Model (4.1GB)
    ↓ Real Response
GUI Chat Display
```

### Components

**real_llm_proxy.py** (new)
- HTTP server on port 9999
- Proxies `/api/inference/chat` to Ollama `/api/generate`
- Handles system prompts, temperature, max tokens
- Provides `/health` endpoint for GUI healthchecks

**ghostlink_gui_tkinter.py** (modified)
- Increased request timeout: 3s → 120s (for LLM inference)
- Configured to connect to proxy on port 9999 via `--backend-url`
- All chat requests now use real responses

**scripts/launch_studio.py** (new, cross-platform)
- Preflight check mode: `python3 scripts/launch_studio.py --check`
  - Verifies Ollama running on 11434
  - Confirms neural-chat model available
  - Reports port readiness
  
- Full launch mode: `python3 scripts/launch_studio.py`
  - Auto-starts Ollama if not running
  - Pulls neural-chat model if missing
  - Starts backend (8003), proxy (9999), GUI
  - Handles cleanup on exit

**scripts/launch_studio.sh** (updated)
- Now delegates to launch_studio.py on all platforms
- Maintains bash interface for user scripts

**crates/ghost-link/src/main.rs** (backend fixes)
- Fixed socket address parsing scope issue
- Changed default port 8000 → 8003 (matches GUI expectation)
- Fixed localhost → 127.0.0.1 for Windows compatibility

## Breaking Changes

## Rollback Plan
If issues arise:
1. Stop all services: `pkill python3 ghost-link ollama`
2. Revert branch: `git revert <commit-hash>`
3. Rebuild backend: `cargo build --release -p ghost-link`
4. Services will return to previous behavior

## Deployment Notes

### Requirements
- Ollama installed (https://ollama.com)
- neural-chat model (auto-pulled if missing, 4.1GB)
- Python 3.9+
- ~500MB disk space for model

### Port Configuration
- Ollama: 11434 (fixed)
- Backend: 8003 (configurable via --port)
- Proxy: 9999 (fixed for GUI)
- GUI: Tkinter window (no port)

### Linux/macOS
```bash
bash scripts/launch_studio.sh --check
bash scripts/launch_studio.sh
```

### Windows
```powershell
python3 scripts/launch_studio.py --check
python3 scripts/launch_studio.py
```

## Known Limitations
1. neural-chat only model (not configurable)
2. Ollama must be pre-installed
3. First inference slow (model loading)
4. 5-10GB total system RAM recommended
