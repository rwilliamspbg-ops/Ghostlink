## 🆘 TROUBLESHOOTING

### GUI Not Showing
- Wait 30 seconds for both services to start
- Check http://localhost:3000 in browser
- Try hard refresh (Ctrl+Shift+R)
- Check Vite dev server in terminal

### Models Not Loading
- Backend still starting (wait 10s)
- Refresh browser
- Check http://127.0.0.1:8003/health
- View backend logs in terminal

### Port Already in Use
- Kill existing process on port 3000 or 8003
- Or use Docker Compose
- Or manually start on different ports

### Tools Not Working
- Enable in Chat tab
- Select model first
- Send message with tool enabled
- Check response for "Tools used"
