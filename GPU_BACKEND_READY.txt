  GET  /api/backends
    List all available backends (CPU and GPU)
    Returns: { available: Backend[], current: string }

  POST /api/backends/switch
    Switch to a different backend
    Body: { "backend": "rocm" | "cpu" }
    Returns: { status: "success" | "error", message: string }

  GET  /api/backends/:name/status
    Get detailed status of a specific backend
    Example: /api/backends/rocm/status
    Returns: { status: "active" | "ready", health: string, ... }
