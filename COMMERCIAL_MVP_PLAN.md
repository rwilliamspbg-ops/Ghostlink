# Ghostlink Commercial MVP Plan

## 1. Product Positioning
Ghostlink is a high-performance distributed inference and scheduling fabric for teams building custom LLM serving stacks.

Primary message:
- Fast planning and scheduling for distributed inference workloads.
- Lower latency and better control than generic orchestration layers.
- Designed for AI engineers who need predictable performance and custom deployment topology.

## 2. Commercial MVP Scope
Focus on a narrow paid slice:
- Self-hosted deployment for a single team.
- Basic model management and inference routing.
- Dashboard for cluster status and model health.
- Support and onboarding package.

## 3. Priority Features
1. One-click local or self-hosted deployment
2. Model management with load/unload/download workflows
3. Basic observability: latency, throughput, queue depth, error rate
4. API compatibility for OpenAI-style inference endpoints
5. Support bundle and deployment guide

## 4. Packaging
- Docker image for easy deployment
- Binary release for Linux
- Python bindings or compatibility shim for existing stacks
- Optional cloud-hosted control plane later

## 5. Pricing Direction
Suggested entry pricing:
- OSS: community edition
- Pro: $99/month per team for self-hosted support and advanced dashboards
- Enterprise: custom for SLA, security, and deployment support
