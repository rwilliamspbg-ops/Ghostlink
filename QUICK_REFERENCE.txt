GHOSTLINK GUI TEST QUICK REFERENCE
===================================

PROBLEM FIXED
- requirements.txt was missing (quickstart.sh is Rust/Cargo-based, GUI is Python)
- Chat always returned mock responses (no real backend)

SOLUTION
- Created requirements.txt with GUI dependencies
- Built backend test server that proxies to Ollama
- All chat responses now use real tinyllama LLM (405MB model)
- 15 automated tests verify no mock responses

QUICK START
===========

1. Install Ollama:
   curl https://ollama.com/install.sh | sh

2. Start Ollama (in one terminal):
   ollama run tinyllama

3. Run tests (in another terminal):
   bash scripts/test_gui_with_ollama.sh

4. (Optional) Start GUI:
   python3 ghostlink_gui.py
   Backend: http://127.0.0.1:8003

TROUBLESHOOTING
===============

Q: "Ollama not running"
A: curl https://ollama.com/install.sh | sh && ollama run tinyllama

Q: "Backend did not start"
A: Check /tmp/ghostlink_backend.log

Q: "tinyllama model not found"
A: ollama pull tinyllama  (takes ~5 min, ~405MB)

Q: "Python dependencies fail"
A: python3 -m pip install --upgrade pip
   python3 -m pip install -r requirements.txt

Q: "GUI shows Backend offline"
A: python3 scripts/backend_test_server.py
   (in another terminal)

VERIFICATION
============

To verify everything works:

1. Test suite passes:
   bash scripts/test_gui_with_ollama.sh

2. Chat returns real LLM responses:
   curl -X POST http://127.0.0.1:8003/api/inference/chat \
     -H "Content-Type: application/json" \
     -d '{"message": "Hello"}'

3. No mock data in models:
   curl http://127.0.0.1:8003/api/models | grep mock
   (should return nothing)

4. GUI connects successfully:
   python3 ghostlink_gui.py
   (should show "online" indicator in sidebar)
